# Administration

Operational components for equipment, global exercises, facilities, users, permissions and audit. Pages receive the server-revalidated role; the backend authorizes every call.

The gym-operated membership and access-control consoles (plans, customers, staff, activation links, face enrollment, devices and credentials) were removed in franja 8e (backend ADR-0026): memberships are sold in the marketplace and confirmed by the business, and there is no physical access control.
