# Auditoría responsive

Diseño mobile-first, navegación adaptativa, grids con breakpoints, controles táctiles,
tablas con overflow contenido y `prefers-reduced-motion`. El temporizador evita renders
encadenados y los medios mantienen contenedores estables. Playwright configura escritorio
y Pixel 7; no se ejecutó la matriz completa 320–768 px porque el backend integrado no pudo
levantarse sin Docker.
