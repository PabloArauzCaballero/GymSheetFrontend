# H9.S3 — UI web inicial de reels (2026-10-11)

## Alcance implementado

- Ruta autenticada `/reels`, enlace en navegación principal.
- Compositor con entradas separadas para captura de cámara del navegador (`capture="environment"`) y selección de archivo; acepta `video/mp4` y `video/quicktime`.
- Publicación por `reelsService.upload(file)` y lectura del feed propio `READY` mediante `reelsService.feed()`.
- La reproducción usa la ruta relativa de media a través del BFF (`/api/backend` + `mediaUrl` del servidor). Al iniciar otro video, la UI pausa el anterior.
- Estados accesibles de carga, validación, error, publicación y lista vacía. Un error de publicación incierto propone actualizar el feed antes de reintentar.
- Pruebas de UI cubren una única llamada durante doble submit, DTO listo en el feed, MIME no admitido, error de publicación con refresh y pausa del video anterior.

Archivos de producto: `apps/web/src/app/(portal)/reels/page.tsx`, `apps/web/src/features/reels/components/reels-page-client.tsx`, `apps/web/src/features/reels/components/reels-page-client.test.tsx`, `apps/web/src/features/reels/index.ts` y `apps/web/src/shared/components/layout/nav-config.ts`.
